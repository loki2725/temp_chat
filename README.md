# Temp Chat

A simple web‑based chat arena built with **Node.js**, **Express**, and **WebSocket**. It provides a minimalistic UI for users to join a chat room, set a username, and exchange messages in real time.

## Features

- Real‑time bi‑directional communication via WebSocket.
- Simple UI with a join screen and chat screen.
- Automatic protocol selection (`ws` or `wss`) based on the page's protocol (HTTP vs HTTPS).
- Ultra‑minimalistic, brutalist styling using only vanilla HTML & CSS.

## Installation

1. Clone the repository (or copy the folder) to your local machine.
2. Open a terminal in the project root (`/Users/lokeshkhola/Desktop/temp_chat`).
3. Install the required dependencies:

```bash
npm install
```

---

## Running the Server

Start the Express server which also serves the static `index.html` and upgrades HTTP connections to WebSocket:

```bash
node server.js
```

The server will listen on `http://localhost:3000` by default. Open this URL in a browser to access the chat UI.

---

## Usage

1. **Join the chat** – Enter a username on the join screen and press **ENTER**.
2. **Send a message** – Type a message in the input field and click **SEND** (or press Enter). Your message, prefixed with your username, will appear in the message pane for all participants.
3. **Real‑time updates** – Messages from other users are displayed instantly without page reload.
